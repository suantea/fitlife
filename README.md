# FitLife

> 训练 + 饮食 + AI 教练，一个就够了。

**FitLife** 是一个面向健身爱好者的 Android 应用。不搞花哨的社交功能，专注做好三件事：**记录训练、跟踪饮食、AI 给建议**。够用、清晰、可持续。

---

## 为什么做这个

市面上的健身 App 要么功能堆砌（花半小时学怎么用），要么过于简单（记了跟没记一样）。FitLife 想找到中间的平衡点：

- 训练模板 → 自动排计划，不用每天想练什么
- 饮食记录 → 自动算热量和宏量营养素，不用手动查表
- AI 教练 → 基于你的真实数据给建议，不是通用的鸡汤

## 核心功能

### 训练系统

**模板驱动，灵活可调**

创建训练模板，设定训练天数、休息安排、每天的部位和动作，系统自动生成每日计划。

```
模板示例：推拉腿 (PPL)
├── Day 1: 胸 + 三头
│   ├── 卧推        4×8
│   ├── 上斜哑铃    3×10
│   └── 绳索下压    3×12
├── Day 2: 背 + 二头
│   ├── 硬拉        4×6
│   ├── 引体向上    3×8
│   └── 弯举        3×12
├── Day 3: 腿
│   ├── 深蹲        4×8
│   ├── 腿举        3×10
│   └── 腿弯举      3×12
└── Day 4: 休息
```

训练时的体验：
- 开始训练后自动计时
- 每组完成后记录重量、次数
- 组间休息倒计时提醒
- 支持 6 大肌群（胸/背/肩/手臂/腿/核心）和 8+ 器械类型

### 饮食追踪

**记录 → 统计 → 建议，一条龙**

```
┌──────────────────────────────────────┐
│  今日饮食                    1,850 kcal │
├──────────────────────────────────────┤
│  蛋白质  ████████████░░  135g / 160g │
│  碳水    ██████████░░░░  180g / 220g │
│  脂肪    ██████░░░░░░░░   52g /  70g │
├──────────────────────────────────────┤
│  早餐    鸡蛋×3 + 全麦面包     420 kcal │
│  午餐    鸡胸肉 + 糙米饭      650 kcal │
│  加餐    蛋白粉 + 香蕉        280 kcal │
│  晚餐    三文鱼 + 蔬菜沙拉    500 kcal │
└──────────────────────────────────────┘
```

- 内置 25+ 常见食物库，支持自定义添加
- 基于 Mifflin-St Jeor 公式计算 BMR + TDEE
- 根据目标（减脂/增肌/维持）给出个性化宏量营养素推荐
- 收藏常吃的食物，快速记录

### 碳水循环

进阶玩法：配置 3-14 天的碳水循环计划，每天设定高碳/中碳/低碳日，各有独立的宏量目标。系统自动按日期轮转。

```
碳水循环示例（4天一循环）：
┌───────┬──────┬──────────┬──────────┬──────────┐
│  Day  │ 类型 │  碳水(g) │ 蛋白(g) │  脂肪(g) │
├───────┼──────┼──────────┼──────────┼──────────┤
│ Day 1 │ 高碳 │   300    │   150    │    50    │
│ Day 2 │ 低碳 │   100    │   180    │    70    │
│ Day 3 │ 中碳 │   200    │   160    │    60    │
│ Day 4 │ 高碳 │   300    │   150    │    50    │
└───────┴──────┴──────────┴──────────┴──────────┘
```

### AI 教练

配置自己的 AI API Key，获得基于你真实数据的个性化建议：

- 根据训练记录、饮食数据、体测数据综合分析
- 每日训练提示和建议
- 对话式问答（像私教一样聊）
- 内置健身知识库（渐进超负荷、恢复原则等循证内容）

支持多家 AI 提供商：Dashscope（通义）、Kimi、OpenAI、自定义兼容接口。

### 日历与历史

- 日历视图纵览训练记录
- 查看每次训练的详细数据
- 体重/体脂变化追踪

## 快速开始

### 安装 APK

直接下载：

[APK 下载链接](https://expo.dev/accounts/nealtts/projects/health-training-app/builds)

### 本地开发

```bash
# 克隆
git clone https://github.com/tianhhe/FitLife.git
cd FitLife

# 安装依赖
pnpm install

# 启动开发服务器（Metro + 后端）
pnpm dev

# 或只启动移动端
pnpm dev:metro
```
